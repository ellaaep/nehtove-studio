# Nehtové studio

Statický web pro GitHub Pages. Stačí nahrát `index.html`, `styles.css` a složku `assets/` do repozitáře.

## Co upravit před zveřejněním

- V `index.html` změnit `mailto:rezervace@studio.cz` na vlastní e-mail.
- Doplnit skutečný název studia, ceny a případně text u rezervace.
- V GitHubu zapnout Pages přes `Settings` → `Pages` → `Deploy from a branch` → `main` → `/root`.
